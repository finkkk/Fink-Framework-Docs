# 常见问题（FAQ）

本页汇总 Fink Framework 各模块在接入和运行过程中最常见的问题，并提供对应的检查方向。

使用方式：遇到运行时异常时，先根据所属模块定位问题，再按照表格中的检查项逐项排查。

## UI 系统

### 面板打开、资源与控件

| 现象 | 原因与处理 |
| --- | --- |
| `Open<T>` 返回空值 | 检查资源 Provider 是否支持同步加载；若资源正在异步加载，改用 `OpenAsync<T>` |
| 找不到面板预制体 | 检查预制体是否位于 `Resources` 下、资源路径是否正确、预制体文件名是否与类型名一致 |
| `GetControl<T>` 获取不到控件 | 检查组件类型和 GameObject 名称；名称区分大小写，并确认 `Awake` 调用了 `base.Awake()` |
| 面板打开后仍不能点击 | 检查目标 Surface 是否有效、Canvas 是否启用、Canvas 是否配置事件相机及 Raycaster |
| 关闭后任务仍在刷新 | 使用 `Context.VisibilityToken` 创建异步任务，并在 `OnDispose` 中解绑外部事件 |

### UI Builder

| 现象 | 原因与处理 |
| --- | --- |
| 创建按钮不可用 | 检查面板名称、脚本路径和预制体路径是否合法，或目标文件是否已存在 |
| 只有脚本没有预制体 | 查看 Console，确认脚本编译成功，且生成类型继承 `BasePanel` |
| 面板能生成但无法打开 | 检查预制体是否在 `Resources` 下、名称是否与类型一致、脚本是否挂在根节点 |
| 示例控件没有回调 | 检查控件名称是否被修改，以及脚本中的类型和 `GetControl<T>` 是否匹配 |
